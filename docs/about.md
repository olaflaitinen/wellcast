## Citing wellcast

If wellcast contributes to your work, please cite it. The repository contains
a `CITATION.cff` file, so GitHub offers ready-made APA and BibTeX entries
under **Cite this repository**.

## Data

wellcast bundles no third-party data. All examples, tests, tutorials and the
app demo use the synthetic field generator
[`make_synthetic_field`](user-guide/datasets.md).
