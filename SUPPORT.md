# Support

## Questions and ideas

Ask usage questions, share ideas and discuss engineering methods in
[GitHub Discussions](https://github.com/olaflaitinen/wellcast/discussions).
Please include the wellcast version and a minimal example.

## Bugs and feature requests

Report bugs and request features through
[GitHub Issues](https://github.com/olaflaitinen/wellcast/issues), using the
issue templates. A good bug report contains the wellcast, Python and operating
system versions and a minimal reproducible example, ideally built on
`wellcast.make_synthetic_field`.

## Security

Report vulnerabilities privately as described in [SECURITY.md](https://github.com/olaflaitinen/wellcast/blob/main/SECURITY.md).

## Documentation

Start with the [documentation](https://olaflaitinen.github.io/wellcast): the
user guide explains the engineering behind each module and the tutorials walk
through complete workflows.
